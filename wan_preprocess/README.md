# Препроцессор Wan, как есть

Три файла из `wan/modules/animate/preprocess` официального репозитория
[Wan2.2](https://github.com/Wan-Video/Wan2.2), скопированные **без правок**.
Лицензия Apache 2.0, копирайт Alibaba Wan Team — заголовки в файлах на
месте и трогать их нельзя. Всего около 2900 строк.

Зачем вендорить, а не ставить пакетом: на PyPI их нет, а из репозитория
пришлось бы тянуть всё Wan целиком ради трёх модулей. Правок нет намеренно —
чтобы обновление сводилось к повторному копированию.

* `pose2d.py` — детектор YOLOv10 и ViTPose, оба ONNX, оба на карте.
* `pose2d_utils.py` — `AAPoseMeta`, разбор ключевых точек.
* `human_visualization.py` — отрисовка скелета в том виде, на котором Wan
  обучался. Именно из-за формата скелета, а не только из-за скорости, мы ушли
  от `OpenposePreprocessor`: на чужом формате персонаж заметно сильнее плывёт.

Веса лежат рядом с сервисом в `models/wan-preprocess` и в образ не попадают.
